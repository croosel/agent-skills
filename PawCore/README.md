# PawCore Agent Skills & Identity Pack

这是 **PawCore** 品牌的数字化资产包，旨在为 Accio Work Agent 提供一键式的品牌身份注入和发品流程标准化。

## 🚀 一键安装 (Quick Install)

在新 Agent 的终端（Terminal）中运行以下命令即可完成部署：

```bash
curl -sSL https://raw.githubusercontent.com/croosel/agent-skills/main/PawCore/install.sh | bash
```

## 📦 包含组件

1.  **商家记忆 (Identity Profile)**：注入 12 年制造传承背景、北美市场偏好及发品硬规则。
2.  **品牌资产 (Brand Assets)**：包含 SOP 指南、详情页模版及 P4P 关键词建议。
3.  **定制技能 (Custom Skills)**：升级 `alibaba-product-publish` 技能，实现主图 Slot 5 & 6 的自动转化优化。

## 🛠️ 使用说明

安装完成后，Agent 将自动获得以下能力：
- **自动背书**：在详情页和公司介绍中自动加入 "Rui Rui family 12-year heritage"。
- **视觉统一**：自动将所有新品的第 5、6 张图配置为 PawCore 专属转化钩子图。
- **起订量控制**：默认针对北美 SMB 卖家设置 50pcs 起订量。
