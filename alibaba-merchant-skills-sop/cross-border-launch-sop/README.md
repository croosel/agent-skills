# 🚀 Cross-Border Launch SOP

> **大勛专属定制版** | 跨境电商发品 SOP - Hybrid Workflow v1.0

## ⚡ 一句话价值

**8 分钟** 完成传统需要 **15-20 分钟** 的新品发布，节省 **~50% Token**，转化率预期提升 **50-70%**。

## 🚀 一键触发

| 你说什么 | 自动启动 |
|---|---|
| "发新品 [产品名]" | ✅ |
| "上架 [产品名]" | ✅ |
| "搬品" | ✅ |
| "新品建模" | ✅ |
| 提供产品图 + Amazon ASIN | ✅ 自动启动 |

## 📋 5 步流程

```
Step 1: 启动建模         →  30 秒
Step 2: 白底化处理       →  30 秒
Step 3: Amazon 数据抓取  →  90 秒
Step 4: 双语 Manifest    → 150 秒
Step 5: 钩子图+利润+上架 → 300 秒
                        ━━━━━━━━━━
                        总计 ~10 分钟
```

## 📦 输入与输出

### 输入（用户提供）
- 1 张原始产品图（任意背景）
- 1 个 Amazon ASIN（市场参考）
- 产品名 + 实际生产成本

### 输出（AGENT 生成）
- 11 张优化图（5 主图 + 6 详情图，含 3 钩子图复用）
- 双语 listing（EN-US + 目标市场语言）
- 3 阶梯定价 + 利润健康报告
- IP 合规检查报告
- 一键上架到国际站

## ⚠️ 常见问题

**Q：必须先做 onboarding 吗？**  
A：强烈建议。无 profile 时会进入"降级模式"，每步都要问你画像信息。

**Q：可以一次发多个 SKU 吗？**  
A：v1.0 仅支持单 SKU。v2.0 将支持批量。

**Q：钩子图必须先做吗？**  
A：是。3 张钩子图是品牌资产，必须先生成（仅一次性投入）。

**Q：能跳过 Amazon 抓取吗？**  
A：可以。说"跳过 Amazon 数据"，但会失去市场验证依据。

**Q：利润健康检查是强制的吗？**  
A：是。AGENT 会自动测算，但定价决策权在你。
