# Hybrid Workflow v1.0：人 + Amazon + AGENT 三方分工

## 🎯 核心理念

**单一主体执行 = 必有短板**

| 主体 | 强项 | 弱项 |
|---|---|---|
| 人（你/大勛） | 商业判断、定价拍板、品味审美 | 数据抓取慢、双语翻译累、批量处理弱 |
| Amazon | 真实市场数据、买家偏好验证 | 不能直接抄（侵权）、文化错位 |
| AGENT | 24/7 高速执行、批量处理、双语生成 | 缺乏商业直觉、易侵权、需要监督 |

**三方组合 = 最大化优势 + 最小化短板**

## 🔧 分工矩阵

| 任务 | 人 | Amazon | AGENT |

| 钩子图 | ✅ 一次性确认风格 | - | ✅ 跨 SKU 复用 |
| 场景图 | ✅ 文化校验 | - | ✅ AI 生成 |
| 利润测算 | ✅ 接受/调整 | - | ✅ 自动计算 |
| IP 合规 | ✅ 最终把关 | - | ✅ 黑名单检查 |
| 上架 | - | - | ✅ 一键执行 |

## ⏱ 时间分配（单 SKU）

```
传统方式（全人工）：
└─ 选品 (30min) → 拍图 (60min) → 文案 (45min) → 翻译 (30min) → 上架 (15min) = 180 分钟

复合方案 v1.0：
├─ 人：5 分钟（提供图 + ASIN + 拍板定价）
├─ Amazon：自动（AGENT 抓取）
├─ AGENT：4-5 分钟（白底/双语/钩子/利润）
└─ 总计：8-10 分钟（节省 95% 时间）
```

## 🚀 触发流程

### 用户输入示例

```markdown
👤 用户：
帮我发个新品。
- 产品图：[附图]
- Amazon ASIN: B0CXPK1HK7
- 产品名：Quinceañera Decoration Set
- 实际生产成本：$2.5/套
```

### AGENT 自动执行

```
[1] 读取 MERCHANT_PROFILE.json + LEARNED_RULES.json (10s)
[2] 创建 project/temp/launch/quinceanera_decoration_set/ (5s)
[3] image_edit 白底化 → 01_main_white_bg.jpg (30s)
[4] spawn browser 抓取 ASIN B0CXPK1HK7 (60s)
[5] 双语 manifest 生成 + IP 黑名单检查 (60s)
[6] 利润健康检查 + 表格输出 (10s)
[7] AI 生成 Slot 2/3/4/7/8/9/11 共 7 张图 (200s)
[8] manifest 校验 + 11 图布局打印 (15s)
[9] 询问用户最终确认 (人工 30s)
[10] 调用 #alibaba-product-publish 上架 (60s)

总计：~7 分钟
```

## 🛡 风险控制

| 风险 | 控制机制 |
|---|---|
| AI 抄袭 Amazon 文案 | Step 4 强制规则：仅作"市场验证"，必须重新创作 |
| IP 侵权 | Step 4 强制：检查 LEARNED_RULES.ip_blacklist |
| 利润低于预期 | Step 5 自动预警：FOB < 70% 触发 ⚠️ |
| 文化错位 | Step 4 双语生成时，必须用目标市场表达习惯 |
| 图片质量低 | 每张图 AI 自评分，< 9/10 自动重生 |
