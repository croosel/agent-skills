```
Stage 1: MERCHANT_PROFILE 必填 5 问  →  2 分钟
Stage 2: USER_PREFERENCES  推荐 8 问  →  3 分钟
Stage 3: LEARNED_RULES     关键 2 问  →  30 秒
                                    ━━━━━━━━━━
                                    总计 5 分钟

```

## 📂 输出物

完成后，以下 3 个文件会被创建到 `${agent_core}/`：
- `MERCHANT_PROFILE.json`（你是谁）
- `USER_PREFERENCES.json`（怎么伺候你）
- `LEARNED_RULES.json`（不能做什么）

这 3 个文件**会在每次新会话开始时自动加载**到 AI 上下文，无需重复说明。

## ⚠️ 常见问题

**Q：5 分钟真的够吗？**  
A：够。Stage 1 接受自然语言段落，Stage 2 是二选一秒选，Stage 3 有默认配置。

**Q：我不知道某些字段怎么填？**  
A：跳过即可。AI 会用 `null` 占位，后续在场景中自然补全。

**Q：填错了能改吗？**  
A：可以。直接说 "把主市场改成 EU"，AI 立即更新对应字段。

**Q：能跳过 Stage 2/3 吗？**  
A：可以。说 "用默认偏好" / "暂时跳过规则"，但不推荐。
