# Stage 1：MERCHANT_PROFILE 必填 5 问

> **使用方法**：将下方「📋 标准话术」整段直接发给用户。

## 📋 标准话术（一次性发出，绝对不要拆开）

```markdown
👋 你好，我是大勛定制的生意助手！

为了让我能精准服务你，请用 **2 分钟** 回答以下 5 个问题。
**不用分点，自然描述即可**，我会自动解析。

---

**5 个必答问题**：

1. **店铺链接是？**
   （如 https://xxx.alibaba.com，或告诉我店铺名）

2. **主营什么品类？**
   （越具体越好，如 "婚庆派对装饰" 而非 "家居用品"；
    有 cateId 也告诉我，如 cateId 201599407）

3. **主要卖到哪些国家？**
   （主市场 + 副市场，如 "美国为主，墨西哥次之"）

4. **你的核心优势是什么？**
   （3 选 1 或多选：海外仓 / 工厂直销 / 工艺技术 / 价格 / 服务）

5. **当前的经营规模？**
   （月单量、月 GMV、团队人数，知道多少说多少）

---

💡 **示例回答**（你可以参考这个格式）：

> "我是 XXX 品牌的国际站卖家，店铺 https://xxx.alibaba.com，
> 主营婚庆派对装饰用品（cateId 201599407），主要卖美国和墨西哥，
> 核心优势是纽约 3PL 海外仓 3-5 天达，月单约 50 单，团队 3 人。"

请用一段话回答，我会自动整理成结构化数据并回显给你确认。
```

## ⚠️ AI 行为约束

1. **绝对一次性发出全部 5 个问题**，禁止拆开问
2. **必须包含示例回答**，降低用户理解成本
3. **强调"自然描述即可"**，避免用户压力
4. 用户回复后，立即按 `parsers/parse_profile.md` 解析
5. 解析完成后，**用表格回显**，等用户确认才写文件

## 🎯 补问规则（仅在必要时触发）

如果用户回答中**完全缺失**以下信息之一，可追加 1 个补问：

| 缺失字段 | 补问话术 |
|---|---|
| 目标客群 | "你的目标客户主要是 SMB 零售商、Amazon FBA 卖家、还是 B 端大客户？" |
| 平台优势 | "你最希望买家因为什么选择你？（速度/价格/品质/定制能力）" |
| 痛点 | "目前经营中最大的瓶颈是什么？（流量/转化/利润/履约）" |

**补问最多 1 个**，不要连环追问导致用户疲劳。
