# Stage 3：LEARNED_RULES 关键 2 问 + 持续追加

> **使用方法**：在 Stage 2 完成后，将下方「📋 标准话术」整段发给用户。

## 📋 标准话术

```markdown
🎯 最后一步！硬性规则只问 2 个最关键的，其余的我会**边用边学**。

---

**Q1. 你有没有需要永久避开的 IP / 品牌禁词？**

举例（婚庆派对类常见禁词）：
- Disney, Stitch, Frozen, Elsa, Anna
- Barbie, Mickey, Minnie
- Marvel, Avengers
- 任何品牌注册商标

请直接列出（用逗号分隔），或回答 "暂无" / "我没思路，给我建议"。

---

**Q2. 有没有发布时必须遵守的硬性规则？**

常见类型：
- 首图：必须白底 RGB(255,255,255)
- 双语：必须 EN-US + ES-MX 双语对照
- MOQ：起订量不能超过 100 PCS
- 利润：FOB 毛利率 < 70% 必须预警
- 价格：不能接受低于 $X 的报价

请按"类型: 规则"格式列出（任意 1-5 条），或说 "用大勛默认推荐规则"。

---

💡 **大勛默认推荐规则**（适用于跨境电商通用）：

```json
{
  "image_rules": ["首图必须白底 RGB(255,255,255), 1024x1024"],
  "language_rules": ["所有 listing 必须双语：EN-US + 目标市场语言"],
  "moq_rules": ["MOQ ≤ 100 PCS, 必须支持 Sample Order"],
  "profit_rules": ["FOB 毛利率 < 70% 触发预警", "必须计算 DDP 到手成本"],
  "compliance_rules": ["禁止使用 Disney/Stitch/Aurora 等 30+ IP 词"]
}
```

回答 "用默认" 即可一键启用。
```

## ⚠️ AI 行为约束

1. **只问 2 个问题**，绝对不要扩展
2. 如果用户回答 "用默认"，直接套用默认规则
3. 如果用户回答 "暂无"，记录空数组，不强迫填写
4. 提供"大勛默认推荐规则"作为快捷选项
